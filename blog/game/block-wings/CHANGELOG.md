# 方块飞行：魔法与英语

通过本地 HTTP 服务或静态站点的 /blog/game/ 访问。Phaser 资源加载使用 HTTP，请不要直接双击 file:// 页面。无需构建、业务后端或 API 密钥。

在仓库根目录运行 `python -m http.server 8765 --bind 127.0.0.1`，然后打开 http://127.0.0.1:8765/blog/game/ 。

## 内容和关卡

50 个单词、50 个原创常用短句，分成元素海湾、森林秘境、美食岛屿、动物乐园、彩虹神殿五关。每关有 A/B 两组，每组 5 个单词和对应 5 个短句。一次五关旅程学习 25 个单词、25 个短句，完成后自动换组；也可以在关卡页手动换组，覆盖全部 50+50 内容。全部词句可在“词库”中查看。

每个学习目标按固定顺序出现：中文单词 → 英文单词 → 中文短句 → 英文短句。击中才播放对应语言的音频，播放结束后才进入下一项。同组内随机排序，已选词组不会在关中改变。每关完成后需要点击按钮进入下一关，方便休息。

## 操作与魔法

鼠标移动或手指拖动，自动射击，无限护盾。普通子弹伤害 1；怪物有血条。

仅击中英文短句（每组学习流程的第 4 步）释放大招。中文单词、英文单词、中文短句只产生轻量碎块和音效。英文短句命中后至少等待 4.3 秒且等待语音结束，再出现下一目标，避免连续堆叠。暂停会冻结所有施法时间线。

50 个词汇各有命名的魔法配置，采用五类施法系统，具有预警、飞行/生长、落地命中、余效等阶段：

- 冰系：3.8 秒暴风雪，冰晶坠落、霜阵、碎雪。落地点 85 像素内伤害 0.9、冻结 1.8 秒。
- 火系：4 秒陨石雨，带火尾的陨石落地后形成燃烧区；落地点 70 像素内伤害 1.6、燃烧 3 秒。
- 爆破系：4 秒连续爆弹，落地爆炸、火球、碎石冲击波；落地点 135 像素内伤害 6。TNT 使用可辨认的炸药箱。
- 雷系：4 秒雷暴，落点预警后天空雷柱击下并连锁其他目标；每个节点 70 像素内伤害 2.5。
- 自然系：4 秒藤蔓破土生长，枝叶缠绕、花叶散落；命中范围 70 像素、伤害 1.5、减速至 20% 持续 3 秒。

这些是本游戏的原创魔法规则。五大类共享独立施法时间线，方块名称、爆弹标记及部分颜色/粒子形态按配置变化，并非 50 套独立渲染引擎。新同系施法会替换旧实例，控制粒子数量。所有伤害由实际落地/生长完成事件触发，不在点击瞬间预扣血。

碰撞无限护盾；紫色能量块提供 9 秒彩虹五连发。暂停、失焦暂停、静音、全屏和减少动态效果可用。

## 语音

assets/speech 下包含 200 个本地 MP3：50 个单词和 50 个短句分别配中文、英文。使用 Edge 在线神经语音生成，中文 Xiaoxiao、英文 Jenny，语速 -10%。运行时直接播放本地文件，网络/文件加载失败时回退系统语音。播放等待上限 12 秒，避免异常音频阻塞游戏。

scripts/generate-speech.py 可续跑生成，需要 Python 的 edge-tts。只生成缺失文件。词库配置位于 curriculum.json，网页使用相同数据的 curriculum.js；编辑时应同步两者。

## 验证

scripts/verify.cjs 检查 50+50 内容、全部 200 个 MP3 的浏览器解码、五关完整 100 次目标命中、中英顺序、关卡切换、暂停、词库、触屏布局和独立战斗规则。需要 Playwright；可用 PLAYWRIGHT_MODULE 指定安装路径。

素材和研究来源见 SOURCES.md。

新增 scripts/verify-spells.cjs 验证五系时间线、50 个命名配置、英文短句独占施法、冷却与暂停。

## 逐物品特效与弹幕更新

当前已迁移到 Phaser 3.90.0，优先使用 WebGL；不可用时使用 Phaser Canvas 兼容渲染并显示提示。引擎和 MIT 许可证保存在 vendor 下，无运行时 CDN 依赖。

item-vfx.js 为全部 50 个物品提供独立图形与动作编排。树木为树冠/树干生长和树根扩散，花为花瓣绽放和散射，叶子为飞叶环绕，木头为圆木坠落，种子为萌芽；动物包含各自的耳朵、翅膀、角、斑纹或口鼻图形，并搭配跳跃、冲锋、游动等动作。伤害类型仍可共享冰、火、雷、爆破、自然五类规则，视觉不再由伤害类别直接决定。词库显示各物品的特效描述。

bullets.js 提供九路扇形、双螺旋、三束激光、星芒散射、波浪弹幕、彩虹弹雨，每 8 秒自动轮换。每 0.075 秒发射一轮、每轮 3—13 发（强化增加 2 发），场内最多保留 600 发。激光为加长高亮弹体，单发伤害 2；其他弹体伤害 1。所有模式无需额外操作。

大招仍只在英文短句命中后触发。verify-items.cjs 检查 50 个不同渲染结果、六种弹幕和实际树/花施法过程。

## Phaser 迁移

入口仍为 game.js，管理课程、语音和战斗规则；phaser-scene.js 管理 Phaser Scene、精灵池、粒子发射器、Graphics、Bloom 和镜头震动。Phaser 的场景 update 驱动游戏，已移除旧版独立 requestAnimationFrame 及逐帧 Canvas 绘制。飞机、目标、怪物、子弹、道具与施法图形均作为单独的 Phaser 对象渲染。

仅在场景启动时使用小型 Canvas 生成单个精灵纹理（方块、飞机、50 个物品图标、冰晶、弹体等），没有把旧游戏整帧画面上传成贴图。目标使用 WebGL Bloom，能量粒子使用加法混合。暂停时粒子寿命和游戏时间一同冻结。

第一关重点升级了冰雹、TNT 爆炸、陨石和雷柱；其余关卡也已迁移到 Phaser 精灵/图形，保留各物品的动作差异。学习顺序、50+50 词库、200 段语音、六种自动弹幕及英文短句独占大招规则保持一致。

scripts/verify-phaser.cjs 使用 HTTP 本地地址验证 WebGL 渲染器、完整五关、100 次学习命中、200 个音频解码、触屏、词库和暂停。运行前启动上述本地服务器。旧 Canvas 测试脚本留作历史逻辑参考，当前端到端测试以 verify-phaser.cjs 为准。

## 2026-09-06：战斗表现与追踪导弹升级

- 新增 `arsenal.js`：Phaser Arcade Physics 对象池负责两侧自动发射的导弹，带角速度限制、加速、重新锁定和实际碰撞伤害；导弹只攻击敌机，不触发学习方块。
- 八种主武器：宽幅散弹、螺旋弹、穿透激光、回旋星刃、波浪炮、交叉弹、脉冲环、水晶分裂弹。自动每 9 秒轮换，顶部“换武器”可直接体验。基础操作仍只需移动鼠标或拖动手指。
- `assets/aircraft-v2.png` 为生成的透明体素飞机图集，包含玩家飞机和三种敌机；`assets/magic-v2.png` 包含熔岩、冰晶、爆炸和电球。通过 Phaser Texture Frame 取图，保留原始 alpha。
- 引擎负责导弹碰撞、13 个有粒子数上限的发射器、飞机倾斜、受击形变、碎片 Tween、冲击波和分层尾迹。大型物品魔法仍只在英文短句阶段释放。导弹普通命中使用小型爆炸。
- 暂停会停止 Arcade Physics、粒子和 Tween；重新开始清理导弹、碰撞代理和临时动画。持续弹幕上限 650，导弹对象池上限 28。
- `node blog/game/scripts/verify-arsenal.cjs` 验证武器轨迹、分裂/穿透、真实导弹命中与重新锁定、暂停清理和手机触摸；`verify-phaser.cjs` 检查完整五关及全部语音。

## 实体方块、命中声音与敌机路线

移除学习方块的 Bloom，保留完全不透明的体素表面；冰块使用蓝色实体材质。方块命中会短暂挤压、弹起并飞溅碎屑。

`enemy-motion.js` 提供六种有不同基础速度的路线：重装巡航、高速斜掠、折线游击、回旋盘绕、蓄力俯冲和蛇形穿梭。移动使用速度积分，冻结会暂停路线时间，击退不会被路线位置覆盖。

`audio-fx.js` 使用缓存噪声与短音调合成撞击声音，覆盖普通命中、激光、冰块、木材、石材及爆炸；独立频率限制避免密集弹幕叠音，朗读期间降低战斗音量。新增枪口闪光、定向火星、装甲碎屑和敌机推进尾迹，共 17 个有上限的粒子发射器。

验证：`verify-impact.cjs` 检查六种轨迹、速度差异、冻结击退、50 种方块的不透明像素、实际 Web Audio 输出信号、静音和暂停粒子；`verify-arsenal.cjs` 与 `verify-phaser.cjs` 继续覆盖导弹、武器、五关及 200 个语音文件。

### 发射与爆炸音效加强

八种主武器分别使用机关炮、双音螺旋、激光扫频、回旋刃、低音波浪、双击、脉冲和晶体音色。导弹发射增加喷射声；爆炸音由高频炸裂、低频下坠轰鸣和延迟碎片声组成，统一由实际爆炸事件触发。声音总线增加动态压缩，朗读时降低音量，静音立即切断已有音效尾声。

`node blog/game/scripts/verify-sounds.cjs` 在真实游戏中检查八种发射音、导弹与爆炸触发，测量压缩后的输出波形，验证静音及恢复。

### 魔法粒子爆发

新增 `magic-particles.js`：魔法在英文短句命中及后续落点分层爆发，包含短闪光、向外扩散的碎片和消散残留。冰系使用冰晶与霜雾，火系使用火团、余烬和烟尘，雷系使用短电弧及离子火花，自然系使用叶片或花瓣，爆破系使用岩屑与火星；其它物品加入自身图标碎片，保留 50 种物品的区别。移除覆盖整片海面的装饰大圆环，调整落点避免集中在顶部 HUD 后。

所有效果使用 Phaser 原生 ParticleEmitter，按屏幕大小及 reduced-motion 减量，有发射预算及每个发射器的粒子上限。暂停和重新开始统一停止或清空，残留最长约 1.5 秒。

`node blog/game/scripts/verify-magic-particles.cjs` 检查英文短句门槛、50 种效果、树与花的独立碎片、暂停重置、粒子上限和消散。当前测试峰值总活动粒子 746（随机场景会变化）。
