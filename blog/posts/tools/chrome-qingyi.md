# Chrome 插件：轻译的功能、安装与使用说明

轻译是一款安装在 Chrome 浏览器里的划词翻译插件。它可以翻译网页中选中的段落，把已译原文标成淡黄色，并在下次点击时直接打开保存的译文。

这篇文章是工具说明页，不能直接替其他网页执行翻译。需要先下载插件、安装到浏览器，再填写自己的 OpenRouter API Key。目前提供本地安装包，尚未上架 Chrome 应用商店。

## 能做什么

| 功能 | 使用方式 |
| --- | --- |
| 划词翻译 | 选中单词或段落，点击旁边的「译」，也可以使用右键菜单。 |
| 中英互译 | 中文默认译为英文，英文默认译为简体中文；也能固定目标语言。 |
| 免费模型 | 动态获取 OpenRouter 免费文本模型，优先使用近一周 Token 使用量较高的模型。 |
| 荧光笔高亮 | 成功翻译后，原文留下淡黄色标记，方便区分读过、译过的内容。 |
| 点击切换 | 单击高亮显示译文，再单击一次收起，不必重新划选。 |
| 本地记录 | 相同原文和目标语言复用已保存译文，刷新网页、重启浏览器后仍可使用。 |
| 手动更新 | 点击译文浮窗里的「更新」，才会重新请求模型并替换译文。 |
| 清除记录 | 可清除当前译文，也可一次清除全部译文和高亮。 |

## 第一步：下载并安装

1. 下载上面的 ZIP 安装包，解压到一个准备长期保留的文件夹，例如 `D:\Tools\轻译`。
2. 在 Chrome 地址栏手动输入 `chrome://extensions`，按回车进入扩展程序页面。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压后**直接包含 `manifest.json` 的文件夹**。
5. 点击浏览器工具栏的拼图图标，找到「轻译 · OpenRouter Free」，可以将它固定到工具栏。

不要直接选择 ZIP 文件，也不要误选解压目录外面的父文件夹。安装后应能在扩展页面看到轻译，当前安装包版本是 **1.0.2**。

如果你已经下载了整个 SystemBlog 仓库，插件目录是 `blog/tool/chrome插件/轻译`，同样选择其中直接包含 `manifest.json` 的文件夹即可。

## 第二步：配置 OpenRouter

1. 登录 OpenRouter，在 [API Keys 页面](https://openrouter.ai/settings/keys)创建自己的密钥。
2. 点击 Chrome 工具栏中的轻译图标，将密钥填入「OpenRouter API Key」。
3. 翻译方向保留「自动识别 · 中英互译」。
4. 模型保留「自动 · 优先使用量最高的免费模型」，点击「保存设置」。
5. 刷新准备翻译的网页。

密钥只需在自己的浏览器里填写，不需要交给作者。免费模型也需要账户和密钥，而且仍然受到请求频率、账户额度、网络和模型可用性的限制；插件不提供无限翻译额度。

模型列表按近一周 Token 使用量排序，这个指标不等于用户人数或翻译质量。插件缓存模型列表一小时，也可以手动点击「刷新列表」。遇到限流、超时或模型不可用时，会尝试其他免费模型，总计最多三个。

## 第三步：翻译、查看与更新

在普通网页上用鼠标选中一段文字，旁边会出现「译」按钮。点击后，浮窗会显示原文、译文和实际使用的模型。浮窗里的「复制译文」可以复制结果，「切换方向」可以更改本次翻译的目标语言。

翻译成功后，原文会留下淡黄色荧光笔高亮。以后**点击高亮原文显示译文，再点一次收起**。点击卡片上的 ×、按 Esc，或点击空白处也可以收起浮窗。

再次划选相同文字时，按钮会显示绿色「✓ 已译」。点击后读取本地记录，不重复消耗模型请求。只有想重新生成译文时，才点击浮窗里的「更新」；如果更新失败，原译文仍保留。

高亮位置会在刷新后尝试恢复。如果网页原文已经改动，或者位置变化后无法唯一匹配，插件不会随意标记其他内容。旧版本保存的译文没有高亮位置，需要重新划选并查看一次，才能补上荧光笔标记。

## 怎么清除译文和高亮

网页翻译浮窗底部有两个按钮：

- **清除当前翻译**：删除这段原文、当前目标语言的译文和对应高亮，保留其他记录。
- **全部清除**：删除所有网页的全部译文和高亮，保留 API Key、模型选择和翻译方向。

插件设置页顶部也有「清除全部翻译记录」。清除会同步移除已打开网页上的对应高亮，且不可恢复。关闭浮窗只是隐藏显示，不会删除记录。

本地最多保存最近写入的 200 条记录，译文和高亮位置合计不超过 3 MiB；超过上限时，会移除最早保存的记录。

## 更新插件

下载新版本后，将文件覆盖到原来的安装文件夹，在 `chrome://extensions` 中找到轻译并点击刷新图标，再刷新正在阅读的网页。

尽量保持安装目录不变。如果从新目录另外加载，Chrome 可能把它识别成另一个扩展，旧扩展的设置和记录不会自动迁移。新扩展也无法替另一个扩展 ID 清除数据；不再使用时，可以在扩展程序页面移除旧扩展。

## 常见问题

### 为什么安装后选中文字没有「译」按钮？

先刷新网页，并确认轻译已启用。插件支持普通 HTTP/HTTPS 网页，不支持 Chrome 内部页面、Chrome 应用商店及内置 PDF 阅读器。输入框和编辑区不会自动显示划词按钮。

### 为什么看不到清除按钮？

当前版本的清除按钮同时在**网页翻译浮窗底部**和**插件设置页顶部**。检查扩展版本是否为 1.0.2，更新后要重新加载扩展并刷新网页。

### 为什么显示 API Key 无效或请求受限？

检查密钥是否完整、账户是否允许访问所选模型，以及网络能否连接 OpenRouter。免费模型可能限流或下线，可以稍后重试，或在设置里刷新列表、切回自动模型。

### 已经换了模型，为什么译文还是一样？

换模型不会自动删除已保存的译文。打开对应浮窗，点击「更新」，才会使用新设置重新翻译。

## 数据保存在什么地方

API Key、译文和高亮位置保存在本机的扩展存储中，不通过插件云同步。为恢复高亮，记录中包含选中的原文、目标语言、位置和页面地址的摘要，不保存明文网址。

首次翻译或主动更新时，选中的文字会发送到 OpenRouter 及模型提供商；已有记录的查看在本地完成。插件不会发送整个页面、Cookie 或网页地址。模型提供商如何处理收到的文字，仍取决于各自的数据政策。
