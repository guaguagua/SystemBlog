# 轻译：Chrome 划词翻译插件

轻译支持中英划词翻译、荧光笔高亮和本地译文记录；点击高亮可显示或收起译文，也可以更新或清除记录。需要安装到 Chrome，并填写自己的 OpenRouter API Key。
