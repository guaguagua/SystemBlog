# Chrome 插件说明：工具目录、安装与更新

## 已有插件

### 轻译：划词翻译与荧光笔标记

适合阅读外文网页时使用。选中文字即可中英互译，已译原文会留下荧光笔高亮；单击高亮可显示或收起译文，保存的记录可以复用、更新和清除。

- **运行要求**：Chrome 浏览器，需要自己的 OpenRouter API Key，首次翻译需要联网。
- **安装方式**：下载 ZIP，解压后通过 Chrome 的开发者模式加载。

## 通用安装方法

1. 打开所需插件的独立说明文章，确认运行要求和需要配置的账号。
2. 从文章提供的链接下载插件，解压到一个固定文件夹。
3. 在 Chrome 地址栏手动输入 `chrome://extensions`。
4. 开启「开发者模式」，点击「加载已解压的扩展程序」。
5. 选择直接包含 `manifest.json` 的文件夹。
6. 按该插件的说明完成配置，并刷新需要使用插件的网页。

每个插件应放在独立目录里。不要直接选择 ZIP，也不要把包含多个插件的总目录作为安装目录。

如果某个插件以后提供应用商店链接，会在它自己的文章中单独标注；目前目录中的轻译提供本地安装包。

## 更新和卸载

更新时，先阅读插件自己的版本说明，再把新文件覆盖到原来的安装目录。在 `chrome://extensions` 中找到对应插件，点击刷新图标，然后刷新相关网页。

尽量保持目录不变。从不同目录加载可能创建另一个扩展 ID，旧数据不一定会自动迁移。不同插件的记录也不会互通。

不再使用某个插件时，可以在扩展程序页面关闭或移除它。关闭用于暂时停用，移除会删除它的扩展数据。如果只想清理缓存或历史记录，优先使用该插件提供的清除功能。

## 使用前看哪些说明

- **功能与适用范围**：它解决什么问题，哪些网页或场景不支持。
- **运行条件**：是否需要联网、API Key、其他账号或本地软件。
- **权限与数据**：需要访问哪些内容，数据存在哪里，哪些内容会发送给外部服务。
- **更新与清除**：如何升级，如何删除记录，卸载是否影响已保存的数据。

这些条件因插件而异，请以各自的使用文章为准。不要将 API Key 或私人数据上传到反馈区。
