# 轻译 · OpenRouter Free

原生 Chrome Manifest V3 扩展，无构建步骤、无运行时依赖。参考沙拉查词的划词浮窗交互，只保留段落翻译。

## 安装

1. 在 Chrome 打开 `chrome://extensions`，开启右上角「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本目录 `D:\AI\SystemBlog\blog\tool\chrome插件\轻译`。
3. 点击插件图标，填写 [OpenRouter API Key](https://openrouter.ai/settings/keys)，保存。
4. 刷新已打开的网页。选中文字，点击浮动「译」按钮；也可右键选择「用轻译翻译选中文字」。

中文默认翻译为英文，英文及其他语言默认翻译为简体中文。混合语言按中英文字符比例判断，结果卡片可以切换方向，设置页可以固定目标语言。

成功翻译后标记「✓ 已译」并保存到本机。再次选中相同文字时，按钮显示绿色「✓ 已译」，点击直接打开保存的译文，不重复调用模型；右键翻译同样复用记录。点击结果卡片里的「更新」才会重新请求模型并替换该译文，更新失败保留原译文。

已翻译的原文会留下淡黄色荧光笔高亮，直接单击高亮原文可显示译文，再单击一次收起；也可以按 Esc 或点卡片的 × 收起。高亮不拆分或替换网页文字节点，支持跨行选区。高亮中的链接，普通点击用于查看译文，Ctrl/Cmd 等修饰键点击保留浏览器行为。

网页译文浮窗底部直接提供「清除当前翻译」和「全部清除」。前者只删除当前原文、当前目标语言对应的一条译文及其所有高亮位置，其他记录保留；后者清除全部网页的译文及高亮。删除会同步到已打开的其他网页，并收起对应浮窗，保留 API Key 和设置。

设置页的「清除全部翻译记录」可删除本扩展保存的全部译文及高亮位置，包括旧版本没有高亮位置的记录，同时取消正在进行的翻译、移除已打开网页上的高亮和译文浮窗。此操作不可恢复，API Key、翻译方向、模型选择及模型目录缓存会保留。升级后先重新加载扩展并刷新旧网页，以便网页收到清除通知。

旧版本如果是同一个扩展 ID，保存的数据可以直接清除。如果从不同目录加载，Chrome 可能将其识别为另一个扩展；不同扩展的数据彼此隔离，新版无法清除另一个 ID 的存储，可在 `chrome://extensions` 中移除旧扩展以删除其数据。

高亮位置随本地记录保存，刷新页面后自动恢复。页面布局变化时，优先验证原位置，再尝试定位唯一且完全一致的原文；找不到或出现多处相同文字时不猜测位置。每条译文最多保存 8 个位置，随译文记录一同淘汰。升级前的旧记录需要重新划选并查看一次才会记录高亮位置，不会重复翻译。

记录按原文（去除首尾空白）和目标语言匹配，跨网页、刷新页面和重启浏览器仍可复用；切换模型不自动作废旧译文，需要点击「更新」。最多保留最近保存的 200 条、总计不超过 3 MiB（含高亮位置），超出后移除最早保存的记录。

## 免费模型

- 使用官方 `GET /api/v1/models?sort=top-weekly&output_modalities=text` 动态获取目录，保持服务端按最近一周 Token 使用量降序的顺序。使用量不等于用户人数或翻译质量。
- 仅保留支持文本输入输出、输入输出价格均为零且无请求费的模型，排除随机/付费路由器。没有写死模型名单。
- 自动使用排名最前的可用模型；手动指定的模型优先。限流、超时或服务不可用时按排名依次尝试，总计最多 3 个；认证错误不重试。
- 目录缓存 1 小时，过期必须重新获取。设置页可以手动刷新。请求同时限制供应商输入、输出价格为零；指定模型不再免费时停止并提示。
- 每次最多 6000 字符；每个模型最长等待约 25 秒。关闭浮窗会取消当前请求。免费模型仍受账户额度、提供商可用性和隐私策略限制。

## 隐私与范围

仅在没有本地记录时点击翻译按钮或右键菜单，或主动点击「更新」后，将选中文字发送至 OpenRouter 及其模型提供商；不发送整个页面、网址、Cookie。单击高亮只读取本地译文，即使旧记录已被移除也不会自动请求模型。翻译记录在本机保存原文与目标语言的 SHA-256 摘要、译文、模型及保存时间；为恢复高亮，另外保存所选原文、DOM 位置和当前页面地址的摘要（不存明文网址）。API Key 和翻译记录保存在本机 `chrome.storage.local`，不云同步，并限制为扩展受信任上下文访问；本机存储并非加密保险箱。

支持普通 HTTP/HTTPS 网页及其中可注入的 iframe；不支持 Chrome 内部页面、Chrome 应用商店、内置 PDF 阅读器。安装前已打开的页面需要刷新。为避免误选敏感内容，输入框、文本域、编辑区不自动显示划词按钮。网页布局过于特殊时可能影响浮窗位置。

## 开发验证

在本目录运行 `npm test`（Node.js 20+）。测试覆盖免费筛选、排名保留、语言方向、免费价格约束、密钥隔离、限流降级、过期目录刷新、取消和输出截断。真实翻译需在本机设置有效 OpenRouter 密钥后验证。

可选浏览器测试需要本机 Chrome 和 Playwright（使用现有安装或单独安装）。`PLAYWRIGHT_MODULE` 可指定 Playwright 包的绝对路径；运行 `node tests/browser-smoke.mjs` 验证模拟翻译的浮窗、复制、错误和窄屏布局，运行 `node tests/extension-smoke.mjs` 在临时 Chrome 配置中加载真实扩展，验证实时模型列表、设置持久化、划词和缺少密钥提示。测试不会修改日常 Chrome 配置，也不会调用付费模型。截图存于被 Git 忽略的 `tests/artifacts/`。
